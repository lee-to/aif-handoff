# Collapse optional project budget fields

**Date:** 2026-08-14 10:31 MSK
**Files:** packages/web/src/components/project/ProjectSelector.tsx, packages/web/src/__tests__/ProjectSelector.test.tsx
**Severity:** low

## Problem

Four optional agent budget inputs were always visible in both the create and edit project dialogs, making the primary project settings harder to scan.

## Root Cause

The budget fields were rendered directly in the form even though they are advanced, optional settings.

## Solution

Grouped the existing inputs inside the shared `Collapsible` component. The section starts closed whenever either dialog opens and retains the existing values and validation when expanded.

## Prevention

- Keep optional advanced settings behind existing disclosure primitives.
- Cover both create and edit dialog visibility in the same regression test.

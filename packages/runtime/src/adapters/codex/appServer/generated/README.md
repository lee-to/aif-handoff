# Codex App Server Generated Protocol

This directory stores the reviewable Codex `app-server` protocol baseline generated by the
installed Codex CLI for the stdio JSONL transport.

Committed artifacts have two different roles:

- All generated TypeScript files are build inputs. They remain committed so a clean clone can
  build `@aif/runtime` without running Codex.
- `schema/codex_app_server_protocol.schemas.json` and
  `schema/codex_app_server_protocol.v2.schemas.json` are self-contained golden snapshots used for
  protocol review and drift detection.
- Per-type and per-method JSON Schemas are generated in a temporary directory during checks but
  are intentionally not committed because they duplicate the aggregate snapshots and are not
  consumed at runtime.

Do not edit generated files by hand. Regenerate after upgrading Codex. The generator requires the
Codex CLI version to match the installed `@openai/codex-sdk` version.

Stable API only; experimental API is intentionally disabled for the runtime default.

Regenerate the committed baseline:

```bash
npm run -w @aif/runtime codex:app-server:protocol:generate
```

Check committed artifacts against the installed CLI:

```bash
npm run -w @aif/runtime codex:app-server:protocol:check
```

Both commands generate the complete upstream protocol in a temporary directory. The generate
command then synchronizes only the committed TypeScript and aggregate-schema baseline, while the
check command fails on TypeScript drift, aggregate-schema drift, or unexpected committed artifacts.

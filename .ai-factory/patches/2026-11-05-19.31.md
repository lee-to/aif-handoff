# Preserve stage completion normalization

**Date:** 2026-11-05 19:31
**Files:** packages/agent/src/coordinator.ts, packages/agent/src/__tests__/coordinator.test.ts
**Severity:** medium

## Problem

CI's attempt-recovery rollout scenarios stopped before implementation. A plan-checker mock completed synchronously, and the new stage wrapper threw while accessing `.finally` on `undefined`.

## Root Cause

Timeout tracking assumed every runner returned an actual Promise. The earlier `Promise.race` boundary normalized plain completion values. The expanded test fixture in the CI merge checkout exposed a compatibility gap absent from the branch's older fixture.

## Solution

Normalize runner results with `Promise.resolve` before attaching settlement tracking. Add regressions for synchronous completion with remediation enabled and disabled; both reproduced the failure before the fix.

## Prevention

- Preserve promise/value normalization when adding lifecycle handlers around an existing async boundary.
- Compare CI's merge-checkout fixtures with branch-local tests when failures differ; newer main tests may exercise additional callers.

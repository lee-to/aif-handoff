# Runtime dependency security refresh

**Date:** 2026-08-04 12:39 MSK
**Files:** `package.json`, `package-lock.json`
**Severity:** high

## Problem

The PR security audit failed on vulnerable production versions of `fast-uri`, `hono`, `ip-address`, and `undici`.

## Root Cause

The lockfile still resolved newly vulnerable releases, and the root override pinned `fast-uri` to `3.1.4`, preventing npm from selecting its patched release.

## Solution

- Updated the `fast-uri` override to `3.1.5`.
- Refreshed only the affected lockfile resolutions: `hono` to `4.13.0`, `ip-address` to `10.4.0`, and `undici` to `7.29.0`.

## Verification

- `npm ci` passes.
- `npm audit --omit=dev --audit-level=high` reports zero vulnerabilities.
- `npm run ai:validate` passes.

## Prevention

Keep the existing production dependency audit required on every pull request and refresh exact overrides when advisories invalidate a pinned release.

# Participant bootstrap prompt hidden by a late Node warning

**Date:** 2026-07-31 17:14 MSK
**Files:** `packages/api/src/scripts/bootstrapParticipantAdmin.ts`, `packages/api/src/__tests__/bootstrapParticipantAdmin.test.ts`
**Severity:** medium

## Problem

`npm run participants:bootstrap` printed database startup logs and then appeared to hang instead of showing the username prompt.

## Root Cause

The interactive prompt was written before Node emitted a pending `DEP0205` deprecation warning from the TypeScript loader. The warning moved the terminal cursor to a new blank line, leaving the process waiting for input with no visible prompt.

## Solution

The bootstrap now yields through one event-loop turn before opening the interactive prompt, allowing pending loader warnings to finish first. A structured `[FIX:participant-bootstrap-prompt]` debug message records the boundary without exposing input. The regression test verifies that pending terminal output completes before the prompt is invoked.

## Prevention

- Flush pending runtime output before starting an interactive prompt from a loader-backed CLI.
- Verify terminal tools in a real PTY, including cursor position after warnings, rather than checking prompt calls only.
- Keep password input hidden and never include credentials in terminal diagnostics.
